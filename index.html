Notas de Rodapé e Detalhes

O HTML é a linguagem padrão para criar páginas web. Com ele, podemos criar conteúdos fortemente destacados e textos com ênfase em itálico. Também é possível destacar informações importantes com uma cor de fundo.

Podemos utilizar a tag sublinhado e exibir textos menores usando a tag small para avisos ou termos. Se quisermos mostrar um preço antigo, usamos R$ 100,00 para o texto riscado. Para alterar cores de forma legada no texto, podemos usar a tag fonte azul.

Fórmulas matemáticas e químicas usam índices: A água é representada por H2O (subscrito) e a área de um quadrado por X2 (sobrescrito).
